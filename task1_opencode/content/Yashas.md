## What I think about AI in software engineering today

AI today acts as a powerful pair programmer that accelerates boilerplate generation and debugging, but it still lacks deep architectural context. It is incredibly useful for scaffolding projects, yet it requires constant oversight to ensure code security and maintainability. We are currently in a phase where AI augments human developers rather than replacing them, shifting the daily focus from syntax memorization to higher-level system design..

## Where software engineering will be in 5–10 years

The role of a software engineer will transition from writing raw code to orchestrating complex, AI-driven microservices and agents. Natural language will become a primary compilation step, with developers spending more time defining constraints, evaluating security, and managing cloud architectures. Traditional coding will still exist for performance-critical systems, but the vast majority of application development will be highly abstracted and automated.

## My hot take on AI

Prompt engineering is a temporary fad that will vanish once models actually learn to understand human intent.
